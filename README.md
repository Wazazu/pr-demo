# PR Demo

A tiny sandbox repository for practicing the GitHub pull request workflow.

## What this is

This repo exists so you can experience the full loop: create a branch, make a
small change, open a pull request, and merge it.

## Getting started

1. Clone the repo: `git clone https://github.com/Wazazu/pr-demo.git`
2. Create a branch: `git checkout -b my-change`
3. Make your edit and commit it
4. Push the branch and open a pull request
